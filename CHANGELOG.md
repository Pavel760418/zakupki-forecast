# Changelog

## Третий релиз — Автозаказ СИКС

### Добавлено
- Переименование пользовательского названия модуля/приложения в **«Автозаказ СИКС»**.
- Постоянный слой привязки SKU → поставщик/контрагент: `data/supplier_mapping.py`.
- Встроенный файл привязки: `data/Привязка_SKU_к_контрагенту.xlsx` (поиск также по исходному Windows-пути, если доступен).
- Опциональный выбор поставщика в Streamlit (по умолчанию — общий расчёт без фильтра).
- Лист итогового Excel `09_Заказ_поставщику` — только при явном режиме расчёта по поставщику.
- CLI-флаг `--supplier` (опционально).

### Изменено
- `streamlit_app.py`: название, пометка «Третий релиз», инструкция, блок выбора поставщика.
- `excel/workbook_builder.py`: условное добавление листа заказа поставщику; упоминание в инструкции книги.
- `config/settings.py`, `config/column_mapping.py`: путь и алиасы колонок привязки.
- `README.txt`, `gui/app.py`: название релиза 3.

### Не изменялось намеренно
- Формулы автозаказа и бизнес-логика ABC / прогноза / рисков.
- Структура листов `00`–`08` при общем расчёте.
- Базовый пользовательский сценарий без выбора поставщика.

### Важно про файл привязки
Исходный файл  
`C:\Users\Администратор\Documents\МР\новый период работы\Закупка\Привязка_SKU_к_контрагенту.xlsx`  
в среде cloud-агента **не был доступен**. В репозиторий встроен файл с типичными
колонками 1С (`Контрагент`, `Код контрагента`, `Артикул`, `Номенклатура`) и демо-SKU
для проверки. Замените `data/Привязка_SKU_к_контрагенту.xlsx` реальной выгрузкой
при наличии — loader подхватит его автоматически.

## Второй релиз

### Добавлено
- Новый слой чтения и нормализации Excel: `data/excel_parser.py`.
- Функции: `normalize_columns`, `detect_sheet`, `detect_header_row`, `parse_sales_file`, `parse_stock_file`, `map_input_columns`, `build_canonical_sales_df`, `build_canonical_stock_df`.
- Расширенная техническая диагностика парсинга (лист, строка заголовка, распознанные колонки, mapping, ключи объединения).

### Изменено
- `data/loaders.py` переведён на новый parser-слой без изменения публичного интерфейса `load_stock_file/load_sales_file`.
- Обновлён стартовый экран `streamlit_app.py`: пометка "Второй релиз", описание новых возможностей загрузки, актуализированная инструкция.
- Обновлён `README.txt` под новый механизм импорта 1С.

### Не изменялось намеренно
- Бизнес-логика расчётов.
- Формулы автозаказа.
- Алгоритмы ABC/прогноза/рисков.
- Архитектура расчётного pipeline.
