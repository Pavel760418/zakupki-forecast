# Changelog

## Четвёртый релиз

### Добавлено
- Детализация заказа по магазинам/подразделениям 1С (опционально; по умолчанию сводно по сети).
- Канонические поля `store`, `barcode`, `purchase_price`, `supplier_name` на каждой строке расчёта.
- Лист `09_Заказ_поставщику` формируется всегда (наименование, количество, штрихкод, цена, сумма).
- Лист `10_Матрица_заказ` при режиме «по магазинам».
- Чтение группировок 1С в остатках (шапка склада) и продажах (шапка подразделения).
- Сведение имён точек: Сочи / Сочи Приморская, Орджоникидзе / Орджоникидзе 11, Флагман и т.д.
- Откат 3 релиза: ветка `cursor/backup-release-3-e9d7`, тег `release-3`.

### Изменено
- Стартовый экран Streamlit: **Четвёртый релиз**, инструкция пользователя, переключатель детализации.
- `03_Расчёт_заказа`: колонки магазин, поставщик, штрихкод, цена, сумма заказа.
- ABC по-прежнему считается по SKU в целом по сети, затем копируется на строки магазинов.

### Не изменялось намеренно
- Формулы автозаказа (прогноз, страховой, заказ).
- Алгоритмы ABC / тренда / рисков.
- Возможность считать без выбора поставщика.

## Третий релиз

### Добавлено / уточнено
- Постоянный слой привязки SKU → поставщик: `data/supplier_mapping.py`.
- Встроенный справочник `data/reference/Привязка_SKU_к_контрагенту.xlsx`.
- Опциональный выбор поставщика в Streamlit (по умолчанию — общий расчёт).
- Лист `09_Заказ_поставщику` в итоговом Excel — только при выбранном поставщике.
- Forward-fill поставщика из merged cells — в списке отображаются **все** поставщики справочника.
- Расчёт по поставщику **не требует** наличия остатков в загруженном файле: отсутствующие SKU берутся из привязки с остатком 0.
- Минимальный целевой остаток **24 шт** на каждый SKU (`SETTINGS["min_stock_target"]`, параметр на `01_Настройки` B20).

### Исправлено
- Ошибка `build_workbook() got an unexpected keyword argument 'supplier_name'` при расчёте по поставщику в Streamlit: имя поставщика передаётся через `meta`, лист `09_Заказ_поставщику` берётся из `meta['supplier_name']`.

### Изменено
- Название приложения: **Автозаказ СИКС**.
- Стартовый экран: пометка **Третий релиз**, обновлённая инструкция пользователя.
- `excel/workbook_builder.py`: лист заказа поставщику + формула докупки до минимального остатка.
- `calculations/reorder.py`: докупка до `min_stock_target`.
- `calculations/pipeline.py`: `allow_empty_sales` для режима поставщика без продаж.

### Не изменялось намеренно
- Базовые формулы прогноза/safety/ABC.
- Базовый сценарий общего расчёта без выбора поставщика.
- Структура существующих листов итогового Excel (кроме опционального нового листа и параметра B20).

## Второй релиз

### Добавлено
- Новый слой чтения и нормализации Excel: `data/excel_parser.py`.
- Функции: `normalize_columns`, `detect_sheet`, `detect_header_row`, `parse_sales_file`, `parse_stock_file`, `map_input_columns`, `build_canonical_sales_df`, `build_canonical_stock_df`.
- Расширенная техническая диагностика парсинга (лист, строка заголовка, распознанные колонки, mapping, ключи объединения).

### Изменено
- `data/loaders.py` переведён на новый parser-слой без изменения публичного интерфейса `load_stock_file/load_sales_file`.
- Обновлён стартовый экран `streamlit_app.py`: пометка "Второй релиз", описание новых возможностей загрузки, актуализированная инструкция.
- Обновлён `README.txt` под новый механизм импорта 1С.

### Не изменялось намеренно
- Бизнес-логика расчётов.
- Формулы автозаказа.
- Алгоритмы ABC/прогноза/рисков.
- Архитектура расчётного pipeline.
