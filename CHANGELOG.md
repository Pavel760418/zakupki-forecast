# Changelog

## Третий релиз

### Добавлено
- Постоянный слой привязки SKU → поставщик: `data/supplier_mapping.py`.
- Встроенный справочник `data/reference/Привязка_SKU_к_контрагенту.xlsx`.
- Опциональный выбор поставщика в Streamlit (по умолчанию — общий расчёт).
- Лист `09_Заказ_поставщику` в итоговом Excel — только при выбранном поставщике.

### Исправлено
- Ошибка `build_workbook() got an unexpected keyword argument 'supplier_name'` при расчёте по поставщику в Streamlit: имя поставщика передаётся через `meta`, лист `09_Заказ_поставщику` берётся из `meta['supplier_name']`.

### Изменено
- Название приложения: **Автозаказ СИКС**.
- Стартовый экран: пометка **Третий релиз**, обновлённая инструкция пользователя.
- `excel/workbook_builder.py`: безопасное добавление листа заказа поставщику без изменения существующих листов/формул.

### Не изменялось намеренно
- Формулы автозаказа и бизнес-логика расчёта потребности.
- Алгоритмы ABC / прогноза / рисков.
- Базовый сценарий общего расчёта без выбора поставщика.
- Структура существующих листов итогового Excel (кроме опционального нового листа).

## Второй релиз

### Добавлено
- Новый слой чтения и нормализации Excel: `data/excel_parser.py`.
- Функции: `normalize_columns`, `detect_sheet`, `detect_header_row`, `parse_sales_file`, `parse_stock_file`, `map_input_columns`, `build_canonical_sales_df`, `build_canonical_stock_df`.
- Расширенная техническая диагностика парсинга (лист, строка заголовка, распознанные колонки, mapping, ключи объединения).

### Изменено
- `data/loaders.py` переведён на новый parser-слой без изменения публичного интерфейса `load_stock_file/load_sales_file`.
- Обновлён стартовый экран `streamlit_app.py`: пометка "Второй релиз", описание новых возможностей загрузки, актуализированная инструкция.
- Обновлён `README.txt` под новый механизм импорта 1С.

### Не изменялось намеренно
- Бизнес-логика расчётов.
- Формулы автозаказа.
- Алгоритмы ABC/прогноза/рисков.
- Архитектура расчётного pipeline.
