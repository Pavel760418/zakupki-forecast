Шаблоны для загрузки в модуль zakupki_forecast
================================================

Файлы:
  Шаблон_остатки.xlsx   (также Template_stock.xlsx)
  Шаблон_продажи.xlsx   (также Template_sales.xlsx)

Как устроено (чтобы не ломать загрузку):
  • Лист «Данные»     — сюда вносите строки. Первая строка = заголовки.
  • Лист «Инструкция» — только для чтения человеком.
  • Модуль читает ТОЛЬКО лист «Данные» (см. data/loaders.py).

Как пользоваться:
  1. Откройте нужный шаблон в Excel.
  2. Прочитайте лист «Инструкция».
  3. На листе «Данные» замените примеры своими строками из 1С.
  4. Сохраните файл.
  5. В программе загрузите его на соответствующем шаге.

Пересоздать шаблоны (если установлен Python + openpyxl):
  python samples/create_templates.py

Запасной генератор без openpyxl:
  python samples/create_templates_stdlib.py
