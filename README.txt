Автозаказ СИКС (zakupki-forecast) — третий релиз
=================================================

Что нового в третьем релизе:
  • название приложения: «Автозаказ СИКС»;
  • опциональный расчёт заказа по выбранному поставщику;
  • встроенная привязка SKU → поставщик
    (data/reference/Привязка_SKU_к_контрагенту.xlsx);
  • в итоговом Excel лист «09_Заказ_поставщику» —
    только если поставщик выбран явно.

Важно: выбор поставщика необязателен.
  • По умолчанию выполняется общий расчёт по всей номенклатуре.
  • Без выбора поставщика поведение совпадает с предыдущими релизами.

Как работает загрузка продаж/остатков (релиз 2+):
  1. Файл сначала читается "сыро" (header=None).
  2. Автоматически определяется лист с данными.
  3. Автоматически определяется строка заголовка.
  4. Колонки нормализуются и мапятся в канонические поля.
  5. Продажи и остатки приводятся к внутреннему формату расчёта.

Канонический формат на вход расчётного движка:
  • Остатки: sku, name, stock, uom, warehouse, sku_key
  • Продажи: sku, name, date, qty, amount, sku_key

Если файл из 1С не читается:
  • откройте его в Excel и пересохраните как "Книга Excel (*.xlsx)";
  • проверьте, что в таблице есть поля номенклатуры и количества.

Локальный запуск:
  streamlit run streamlit_app.py

CLI:
  python run_cli.py --stock <xlsx> --sales <xlsx> --from DD.MM.YYYY --to DD.MM.YYYY --order-days 14
