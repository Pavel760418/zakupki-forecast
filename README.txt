Автозаказ СИКС (zakupki-forecast) — четвёртый релиз
====================================================

Что нового в четвёртом релизе:
  • детализация заказа сводно по сети ИЛИ по магазинам/подразделениям 1С;
  • на листе «03_Расчёт_заказа»: магазин, поставщик, штрихкод, цена приходная;
  • лист «09_Заказ_поставщику» всегда: наименование, количество, штрихкод, цена, сумма;
  • при расчёте по магазинам — лист «10_Матрица_заказ» (SKU × точка);
  • группировки 1С (шапка «Адлер», затем товары) читаются как магазин.

Откат на третий релиз:
  • ветка GitHub: cursor/backup-release-3-e9d7
  • тег: release-3
  • в Streamlit Cloud можно переключить Main file / branch на эту ветку.

Выбор поставщика необязателен.
  • По умолчанию — все контрагенты (поставщик указан в строке).
  • Выбор «ООО СФЕРА» фильтрует SKU этого контрагента.

Как работает загрузка (релиз 4):
  1. Файл читается «сыро» (header=None).
  2. Ищутся лист, заголовок, группировки склада/подразделения.
  3. Сопоставляются имена точек (Сочи = Сочи Приморская, Флагман = Обособленное подразделение Флагман).
  4. Канон: остатки sku/store/stock/barcode; продажи sku/store/date/qty.

Локальный запуск:
  streamlit run streamlit_app.py

CLI:
  python run_cli.py --stock <xls> --sales <xls> --from 01.08.2026 --to 16.08.2026 --order-days 14 --by-store
