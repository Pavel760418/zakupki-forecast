Автозаказ СИКС — импорт Excel из 1С (третий релиз)
===================================================

Третий релиз:
  • название модуля/приложения: «Автозаказ СИКС»;
  • опциональный расчёт заказа в разрезе поставщика (SKU ↔ контрагент);
  • лист «09_Заказ_поставщику» в итоговом Excel — только при выборе поставщика;
  • без выбора поставщика — прежний общий расчёт (поведение по умолчанию).

Второй релиз (сохранено):
  • новые шаблоны выгрузок 1С для продаж и остатков;
  • служебные строки до таблицы;
  • заголовок не в первой строке;
  • merged cells, пустые строки, "Unnamed" колонки;
  • нестандартные названия листов;
  • широкий формат продаж (даты в колонках, пары Количество/Сумма).

Как работает загрузка продаж/остатков:
  1. Файл сначала читается "сыро" (header=None).
  2. Автоматически определяется лист с данными.
  3. Автоматически определяется строка заголовка.
  4. Колонки нормализуются и мапятся в канонические поля.
  5. Продажи и остатки приводятся к внутреннему формату расчёта.

Привязка SKU к поставщику (релиз 3):
  • файл: data/Привязка_SKU_к_контрагенту.xlsx
  • модуль: data/supplier_mapping.py
  • выбор поставщика в UI — опционален; по умолчанию общий расчёт.

Канонический формат на вход расчётного движка:
  • Остатки: sku, name, stock, uom, warehouse, sku_key
  • Продажи: sku, name, date, qty, amount, sku_key

Диагностика для разработчика:
  • выбранный лист;
  • номер строки заголовка;
  • распознанные колонки;
  • mapping входных колонок;
  • приоритет ключей объединения.
  (см. логи `zakupki_forecast.loaders` / `zakupki_forecast.supplier_mapping`)

Если файл из 1С не читается:
  • откройте его в Excel и пересохраните как "Книга Excel (*.xlsx)";
  • проверьте, что в таблице есть поля номенклатуры и количества.
